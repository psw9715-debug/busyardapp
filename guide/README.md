# 차고지 안내 (1·2차고지)

밤 21:30 ~ 00:40, 차가 들어올 때마다 **뒤 세 자리**를 누르고
**폰을 돌려 기사님께 보여준다.** 화면에는 숫자 하나만 남는다.

## 쓰는 법

1. 아이폰 사파리로 `…/guide/` 를 연다
2. 공유 → **홈 화면에 추가**

### 출근하면 먼저 한 바퀴

차고지가 비어 있지 않다. 상단 **순회** 를 누르고 이미 서 있는 차를 자리 순서대로 찍는다.
빈 자리는 **건너뛰기**. 배치도에서 칸을 누르면 그 자리로 커서가 간다.
다 돌았으면 **순회** 를 다시 눌러 끈다.

### 안내

- 세 자리를 누르면 **바로** 자리가 정해진다. 확정 버튼은 없다 (앞자리 `1` 은 화면에만 있다)
- 숫자가 화면을 꽉 채운다. 그대로 돌려서 보여준다
- **화면 아무 데나 누르면** 키패드로 돌아온다
- 오른쪽 아래 동그라미로 색을 바꾼다 — 흰/빨강 → 검정/흰 → 흰/검정.
  **마음에 드는 색에서 나가면 그 색을 기억한다**
- **아무것도 묻지 않는다.** 소스가 없거나 모르는 번호여도 알아서 자리를 정한다.
  휴차인 걸 알고 넣을 때만 `휴차` 키를 먼저 누른다
- 잘못 넣었으면 **직전 취소**, 또는 배치도에서 칸을 눌러 **비우기**.
  배정은 늘 첫 빈칸을 찾으므로 지운 자리가 그대로 다음 차례가 된다
- 같은 차를 다시 넣으면 **옮길까요?** 를 묻는다

### 배치도는 사무실에서 내다보는 그대로다

엑셀에 그려 둔 자리 배치가 곧 **창밖으로 보이는 주차장 모습**이라, 화면도 그대로 그린다.

- 위에서부터 **3열 → 2열 → 1열**. 한 줄은 가로로 한 줄
- **1차고지는 왼쪽부터** 채운다 (`1-1` 이 맨 왼쪽)
- **2차고지는 오른쪽부터** 채운다 (`2-1` 이 맨 오른쪽)
- 3차고지·한노·민노도 같이 그린다. 순회 때 여기도 적어 두면 나중에 손이 덜 간다

이 격자는 `구차고지.xlsx` 에서 읽어 온 것이라 화면과 인쇄가 같은 판을 쓴다.

### 관리

- **최신 버전 받기** — 깃허브에 올라간 새 버전을 강제로 받는다.
  서비스 워커와 캐시를 지우고 주소에 표를 붙여 다시 받으므로,
  화면이 옛것 같으면 이걸 누르면 된다. **적어 둔 차량번호는 지워지지 않는다**
- 그날 자료 다시 받기 · 안내 음성 켜고 끄기
- 오늘 입력 전부 지우기 (두 번 눌러야 실행)
- 지금 도는 버전과 그날 자료 대수, 컷오프를 여기서 확인한다

## 자리를 정하는 규칙

**1차고지** — 출차시각을 보지 않는다. 휴차인지만 본다.

```
휴차·낮 출차 → 맨 뒷열, 1-42 부터 앞으로
1015 / 1016  → 1-41 / 1-42 (61번 전용). 차 있으면 가장 가까운 빈칸
그 외        → 1-1 → 1-2 → 1-3 … 번호 순서대로

안내 숫자 = 홀수 1(앞줄) · 짝수 2(뒷줄) · 1-30~1-42 는 3
```

**2차고지**

```
1열   6시까지 나가는 차
2열   6시 15분 이후에 나가는 늦은 차 · 휴차
3열   1열과 같은 빠른 차, 또는 2열에 못 넣은 늦은 차
```

가운데에 늦은 차가 오면 아침에 편하지만 꼭 그래야 하는 것은 아니다.
앞에서부터 차례로 빠져도 되고 뒤에서부터 후진으로 빠져도 된다.
그래서 **한 줄이 차면 옆 줄로 넘길 뿐 멈추지 않는다.**

**출차시각을 모르면 묻지 않는다.** `1열 → 2열 → 3열` 순서로 채운다.
그렇게만 넣어도 아침에 빠져나가는 데 문제가 없다.

컷오프(`06:15`)는 그날 소스에서 2열 정원에 맞게 자동으로 잡는다. 실측 4일 모두 같은 값이었다.

## 소스 (그날 배차 자료)

폰은 사내 `Z:` 에 닿을 수 없다. 그래서 **Z: 를 읽을 수 있는 사무실 PC 가 다리** 역할을 한다.

```
Z:\...\<MMDD>\...xlsx  ──push_source.py──▶  guide/data/<날짜>.json  ──▶  폰
      시트 "차고지참고"                        읽고 · 만들고 · push
```

```bash
python tools/push_source.py            # 근무일 + 1일
python tools/push_source.py --no-push  # 파일만 만든다
```

읽는 날짜는 **근무일 + 1일**이다. 밤에 들어오는 차는 다음날 아침 나가는 차라서다.
폴더·파일 이름은 해마다 바뀌지만 시트 이름 `차고지참고` 는 그대로라 그걸 축으로 찾는다.
그날 폴더가 아직 없으면 오류가 아니라 "아직 안 올라옴" 으로 끝난다.

앱은 켤 때 한 번 받아 폰에 남긴다. 그 뒤로는 전파가 없어도 그날 내내 돈다.
못 받으면 손으로 넣는 방식으로 떨어질 뿐, 앱은 그대로 쓸 수 있다.
