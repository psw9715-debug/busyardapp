# 차고지 순회 음성입력

6차고지(신차고지)를 순회하며 차량번호를 음성으로 기록하고, 사무실에서
기존 엑셀 출력물과 같은 모양으로 인쇄하는 아이폰용 웹앱(PWA).

맥이 없어도 되고, 7일마다 재설치할 필요도 없다. 사파리로 한 번 열어
홈화면에 추가하면 끝.

## 쓰는 법

1. 아이폰 사파리로 배포 주소를 연다
2. 공유 버튼 → **홈 화면에 추가**
3. 홈화면 아이콘으로 실행 (주소창 없는 전체화면으로 뜬다)

순회할 때:

- **음성 입력 시작**을 누르고 평소 부르던 대로 말한다 — **"천칠백이십오"** 처럼
  한국식으로 단위를 붙여 부르면 된다. `1725`, "일칠이오" 같은 형태도 받는다
- "천"을 빠뜨리고 **"칠백이십오"** 라고만 해도 1000번대로 알아서 채운다
- 빈 자리는 **"공차"** (빈칸 / 패스 / 없음 도 같은 뜻)
- 잘못 들어갔으면 **"이전"** 또는 **"정정"** — 한 칸 되돌아간다
- 음성이 안 될 땐 **키패드** 버튼. 앞자리 1은 고정이라 세 자리만 누르면 된다
- 배치도의 아무 칸이나 누르면 그 자리로 건너뛴다. 예를 들어 69번을 눌러 넣으면
  **그다음은 70번**을 받는 상태가 된다

사무실에서 **인쇄** 버튼 → 프린터 와이파이 이름을 확인하는 화면이 뜨고,
연결한 뒤 누르면 아이폰 인쇄 시트(AirPrint)로 출력된다.

인쇄물은 A4 한 장에 들어가며 지금 쓰는 종이(`신차고지` 시트)와 똑같다. 순회 순번은 걸어갈 때만
쓰는 것이라 인쇄되지 않고, 주차장 바닥에 칠해진 고정번호만 그대로 남는다.
공차도 찍지 않는다 — 종이에서는 빈 칸이 곧 공차다.

### 진단 화면에서 켜고 끄는 것

우측 상단 **진단**에서 마이크 권한·전파·설치 상태를 확인할 수 있고,
아래 두 가지를 눌러서 켜고 끈다 (둘 다 기본 꺼짐).

- **음성 넘어가는 속도** — 말이 멎고 몇 ms 뒤에 확정할지. 번개(120) /
  아주 빠름(200, 기본) / 빠름(300) / 보통(450) / 느림(700)을 눌러가며 고른다.
  단, **다 부른 번호는 이 값과 무관하게 거의 바로 넘어간다** (아래 참고).
- **키패드 숫자 읽기** — `7`을 누르면 "칠" 하고 읽어준다 (기본 켜짐).
  자리 입력 키패드와 **찾을 차량 키패드** 모두에서 읽어준다.
  한 글자라 또렷하게 들리도록 천천히 낸다. 빨리 연달아 누르면 앞 소리를 끊고
  방금 누른 것을 읽는다.
- **다음 자리 안내 음성** — 입력될 때마다 "25번" 하고 다음 자리를 읽어준다.
  에어팟 끼고 화면을 안 볼 때 쓴다.
- **키패드 입력 되읽기** — 키패드로 `734`를 누르면 **"천칠백삼십사"** 라고
  빠르게 확인해 준다. 눌러서 켜면 실제 속도로 미리 들려준다.

맨 아래 **오늘 입력·대상 전부 지우기** 는 두 번 눌러야 실행된다.
차량번호와 찾을 차량 목록을 함께 지운다 (저장해 둔 일지는 남는다).

### 회차 (1회차 / 2회차)

맨 위 **1회차** 를 누르면 2회차로 바뀐다.

2회차는 1회차 때 **비어 있던 자리에 새로 들어온 차**를 채우러 가는 것이다.
그래서 회차를 바꿔도 앞서 적은 것은 그대로 남고, 커서만 첫 빈 칸으로 간다.
입력하면 그다음 빈 칸으로 건너뛴다 — **공차도 빈 칸으로 친다.** 공차는 그때
차가 없었다는 뜻이라 그 사이에 새로 들어왔을 수 있기 때문이다.

2회차를 도는 동안에는 1회차 기록이 죽은 색으로 흐려져서, 아직 차가 들어오지
않은 자리가 한눈에 도드라진다.

순회 판은 하루에 하나이고, 회차는 각 입력에 표시로 붙는다. 배치도에서
**1회차는 차분한 초록, 2회차는 밝은 민트**로 칠해진다. 음성이든 키패드든 같은
회차면 같은 색이다 — 구분해야 하는 것은 입력 방법이 아니라 회차다.

2회차에서 **"이전"** 은 이번 회차에 넣은 것만 되돌린다. 1회차 기록은 건드리지 않는다.

**2회차 기록이 하나라도 있으면 1회차 번호가 흐린 회색으로 찍힌다.** 2회차에 적은
것만 진한 검정이라, 종이만 보고도 무엇이 들어오고 무엇이 바뀌었는지 바로 안다.
차가 옮겨가서 1회차 자리의 번호를 2회차에 고쳐도 그 칸은 진하게 나온다.

판단 기준은 **판에 적힌 내용**이지 지금 어느 회차 모드인지가 아니다. 모드로
정하면 1회차로 되돌려 놓고 인쇄했을 때 구분이 통째로 사라진다.

### 배치도 확대

두 손가락으로 벌리면 배치도가 가로·세로 같은 비율로 커진다(최대 4배).
커진 만큼 스크롤도 따라오므로 가운데 칸도 손가락으로 정확히 짚을 수 있다.
왼쪽 아래 배율 칩을 누르면 원래대로.

### 찾기

상단 **찾기** — 뒤 세 자리를 누르면 그 번호가 몇 번 자리에 있는지 바로 나온다.
결과를 누르면 배치도에서 그 칸을 파랗게 짚어주고 화면을 그리로 옮긴다.
사무실에서 "1727호 키 가져와" 할 때 쓴다.

### 찾을 차량 (CCTV / KEY)

상단 **대상** — 회수해야 하는 차량을 미리 넣어둔다 (최대 10대).
**CCTV** 와 **KEY** 중 하나를 고르고 번호를 누르면 목록에 들어간다 (기본 CCTV).
순회 중 그 번호가 입력되면:

- 다른 소리와 구분되는 알람이 울리고
- **"비디오"**(CCTV) 또는 **"열쇠"**(KEY) 를 앞에 붙여 번호와 자리를 읽어주고
- 배치도의 그 칸이 **CCTV는 빨갛게, KEY는 파랗게** 바뀐다

버튼의 `3/3` 은 넣어둔 대수 중 몇 대를 찾았는지다. 목록은 앱을 껐다 켜도 남으므로
다음 순회 전에 필요 없는 것은 ✕ 로 뺀다.

### 일지 보관

상단 **일지** — 그날 순회를 마치고 **오늘 순회 저장하기** 를 누르면 그 시점의
차량번호 배치(**1·2회차 모두**)와 찾을 차량 목록이 통째로 남는다. 날짜당 하나이며
다시 누르면 그날 것을 최신으로 덮어쓴다.

목록에서 **불러오기** 를 누르면 그날 것이 지금 화면으로 되살아난다. 지금 입력을
덮어쓰므로 두 번 눌러야 실행된다.

키패드를 열면 음성 입력이 멈춘다(숫자 읽는 소리를 받아 적지 않도록).
닫아도 다시 켜지지 않으니, 음성으로 돌아갈 때 직접 누른다.

### 자리마다 인식을 새로 시작한다

사파리는 한 번 켜진 동안 들은 말을 계속 이어붙여서 준다. 그 위에서 "이번에 새로
늘어난 부분"만 골라내는 방식은 말이 길어질수록 어긋나기 쉽다. 그래서 한 대를 넣고
나면 인식을 끊었다 곧바로 다시 켠다. 자리마다 빈 종이에서 출발하는 셈이다.
(손으로 껐다 켜면 잘 되던 것과 같은 상태를 앱이 자동으로 만든다.)

확정 직후는 이미 말이 멎은 뒤라 끊는다고 말이 잘릴 일은 없다.

### 왜 "천칠백이십사"는 바로 넘어가는가

사파리는 말이 끝나고도 한참 뒤에야 인식을 확정해 준다. 그래서 앱이 스스로
"말이 멎었다"고 판단해 넘긴다. 그런데 무작정 빨리 끊으면 "천칠백"에서 잘려
1700이 들어가 버린다.

모든 번호가 네 자리라는 규칙 덕에 이걸 구분할 수 있다. "천칠백"은 아직
"천칠백이십사"가 될 수 있지만, **일의 자리까지 부른 번호는 더 이어질 수 없다.**
그래서 다 부른 번호는 120ms 만에 넘기고, 덜 부른 번호만 위에서 고른 시간을
기다린다.

### 차량번호 규칙

이 차고지 차량은 전부 1000번대(첫 자리가 항상 1)다. 이걸 이용해서:

- 세 자리만 들리면 앞에 1을 붙인다 (`042` → `1042`)
- 첫 자리가 1이 아니게 들리면 1로 고친다 (`7042` → `1042`)
- 이렇게 보정된 칸은 호박색 테두리로 표시되니 나중에 확인하면 된다

## 저장되는 곳

입력한 차량번호는 **폰 안에만** 저장된다(localStorage). 서버로 보내지 않고,
앱을 껐다 켜도 그날 순회 내용은 그대로 남아 있다. 야간 근무를 감안해
오전 9시를 기준으로 날짜를 넘긴다(새벽 3시 입력도 전날 순회로 묶임).

## 개발

정적 파일뿐이라 빌드 과정이 없다. 파이썬만 있으면 된다.

```bash
python -m http.server 5180
```

`http://localhost:5180` 접속. 단, **마이크는 HTTPS 또는 localhost에서만** 동작한다.

### 배치도 데이터 다시 만들기

`src/yard-data.js`는 엑셀에서 자동 생성한 파일이라 직접 고치지 않는다.
배치가 바뀌면 원본 엑셀을 `reference/차고지 프린트.xlsx`에 두고:

```bash
python tools/build_yard.py
```

`신차고지-순서` 시트의 병합 셀을 읽어 15열 × 20행 그리드로 변환한다.
**자리 수는 엑셀이 정한다.** 번호가 1부터 연속이 아니면(빠지거나 겹치면) 오류로 멈춘다.
구역이 늘어 번호가 늘어나도 앱 코드는 손댈 필요가 없다.

### 테스트

브라우저로 연다 (Node.js 불필요):

- `tools/test.html` — 한글 숫자 파서 (79건, 1000~1999 왕복 검사 포함)
- `tools/voice.test.html` — 음성 엔진의 확정 처리·자동 확정·자리마다 재시작·되먹임 차단 (36건)

탭 제목에 `PASS n` / `FAIL n`이 뜬다.

### 배포

`src/build.js`(앱에 표시되는 버전)와 `sw.js`의 캐시 이름을 함께 갱신한다.
**배포 전에 반드시 실행해야** 아이폰이 옛 파일을 계속 쓰는 일이 없다.

```bash
python tools/stamp_build.py
```

그 뒤 커밋하고 push 하면 GitHub Pages가 알아서 올린다.

## 구조

```
index.html          화면 뼈대
src/app.js          화면 조립, 입력 처리, 인쇄
src/app.css         야간용 다크 UI + 인쇄 전용 레이아웃
src/plate.js        한글/아라비아 숫자 → 차량번호 (브라우저 API 없음, 순수 로직)
src/voice.js        iOS 사파리 음성 인식 래퍼, 소리·안내음성
src/store.js        localStorage 저장 (순회 데이터 + 일지 보관)
src/yard-data.js    자동 생성된 배치도 (수정 금지)
src/build.js        자동 생성된 배포 버전 (수정 금지)
version.json        배포 버전 확인용 (수정 금지)
tools/build_yard.py 엑셀 → yard-data.js
tools/stamp_build.py 배포 버전 도장
sw.js               오프라인 캐싱
reference/          원본 엑셀 등 (저장소에 올리지 않음)
```

## 알려진 제약

- **음성 인식은 인터넷이 필요하다.** 애플 서버로 보내서 인식하기 때문에 전파가
  약한 곳에서는 안 된다. 이럴 때 쓰라고 키패드를 넣어뒀다. 앱 자체는 오프라인에서도
  뜨고 입력·저장은 정상 동작한다.
- iOS 사파리는 발화가 끝날 때마다 인식을 끊는다. 앱이 자동으로 다시 켜지만
  아주 짧은 공백이 생긴다. 한 자리씩 또박또박 부르는 게 정확하다.
- 에어팟을 쓸 때 안내 음성이 자기 마이크로 다시 들어가지 않도록, 말하는 동안
  인식을 잠깐 막는다.
- **프린터 와이파이는 앱이 대신 잡아줄 수 없다.** iOS에는 웹앱이 쓸 수 있는
  와이파이 API가 없고, 네이티브 앱이라도 `NEHotspotConfiguration` 권한(유료 개발자
  계정)이 필요하다. 단축어 앱에도 특정 네트워크 접속 동작이 없다. 그래서 인쇄를
  누르면 골라야 할 이름(`DIRECT-s0-EPSON-WF-C579R Series`)을 띄워주는 데까지만 한다.

## 새 버전 받기

앱을 켤 때마다 `version.json` 을 캐시를 건너뛰고 받아와 지금 돌고 있는 것과 비교한다.
다르면 캐시와 서비스 워커를 지우고 알아서 다시 받는다. 사용자가 할 일은 없다.

여기에 더해 `stamp_build.py` 가 **모듈과 스타일 주소에 `?v=` 를 붙인다.** ES 모듈과
CSS 는 페이지를 새로고침해도 브라우저가 캐시해 둔 것을 그대로 쓰기 때문에,
파일만 새로 올려서는 옛 코드가 계속 돌 수 있다. 주소가 바뀌면 다른 파일로 보므로
반드시 새로 받아간다. **배포 전 `stamp_build.py` 를 빼먹으면 이 문제가 재발한다.**

한 번 받아봤는데도 그대로면 무한 새로고침 대신 화면에 알리기만 한다. 그때는
**진단 → 최신 버전 받기** 를 누른다. 입력해 둔 차량번호는 어느 쪽이든 지워지지 않는다.

그래도 안 되면 설정 → Safari → 고급 → 웹사이트 데이터에서 해당 항목을 지운다.

## 자리를 늘릴 때

엑셀 `신차고지-순서` 시트에 번호를 이어서 적고 `python tools/build_yard.py` 를
다시 돌리면 끝이다. 앱 코드에 자리 수를 박아 둔 곳은 없다.
번호가 1부터 연속이기만 하면 되고, 빠지거나 겹치면 생성기가 오류로 멈춘다.
