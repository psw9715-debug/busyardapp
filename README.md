# 차고지 순회 음성입력

6차고지(신차고지) 109자리를 순회하며 차량번호를 음성으로 기록하고, 사무실에서
기존 엑셀 출력물과 같은 모양으로 인쇄하는 아이폰용 웹앱(PWA).

맥이 없어도 되고, 7일마다 재설치할 필요도 없다. 사파리로 한 번 열어
홈화면에 추가하면 끝.

## 쓰는 법

1. 아이폰 사파리로 배포 주소를 연다
2. 공유 버튼 → **홈 화면에 추가**
3. 홈화면 아이콘으로 실행 (주소창 없는 전체화면으로 뜬다)

순회할 때:

- **음성 입력 시작**을 누르고 평소 부르던 대로 말한다 — **"천칠백이십오"** 처럼
  한국식으로 단위를 붙여 부르면 된다. `1725`, "일칠이오" 같은 형태도 받는다
- "천"을 빠뜨리고 **"칠백이십오"** 라고만 해도 1000번대로 알아서 채운다
- 빈 자리는 **"공차"** (빈칸 / 패스 / 없음 도 같은 뜻)
- 잘못 들어갔으면 **"이전"** 또는 **"정정"** — 한 칸 되돌아간다
- 음성이 안 될 땐 **키패드** 버튼. 앞자리 1은 고정이라 세 자리만 누르면 된다
- 배치도의 아무 칸이나 누르면 그 자리로 건너뛴다. 예를 들어 69번을 눌러 넣으면
  **그다음은 70번**을 받는 상태가 된다

사무실에서 **인쇄** 버튼 → 프린터 와이파이 이름을 확인하는 화면이 뜨고,
연결한 뒤 누르면 아이폰 인쇄 시트(AirPrint)로 출력된다.

인쇄물은 지금 쓰는 종이(`신차고지` 시트)와 똑같다. 순회 순번 1~109는 걸어갈 때만
쓰는 것이라 인쇄되지 않고, 주차장 바닥에 칠해진 고정번호만 그대로 남는다.

### 진단 화면에서 켜고 끄는 것

우측 상단 **진단**에서 마이크 권한·전파·설치 상태를 확인할 수 있고,
아래 두 가지를 눌러서 켜고 끈다 (둘 다 기본 꺼짐).

- **음성 넘어가는 속도** — 말이 멎고 몇 ms 뒤에 확정할지. 빠름(300) / 보통(450) /
  느림(700)을 눌러서 돌려가며 고른다. 짧을수록 다음 자리로 빨리 넘어가지만,
  번호를 중간에 끊어 말하면 두 개로 쪼개질 수 있다.
- **키패드 숫자 읽기** — `7`을 누르면 "칠" 하고 바로 읽어준다 (기본 켜짐).
- **다음 자리 안내 음성** — 입력될 때마다 "25번" 하고 다음 자리를 읽어준다.
  에어팟 끼고 화면을 안 볼 때 쓴다.
- **키패드 입력 되읽기** — 키패드로 `734`를 누르면 **"천칠백삼십사"** 라고
  빠르게 확인해 준다. 눌러서 켜면 실제 속도로 미리 들려준다.

맨 아래 **이 회차 입력 전부 지우기** 는 두 번 눌러야 실행된다.

키패드를 열면 음성 입력이 자동으로 멈추고(숫자 읽는 소리를 받아 적지 않도록),
키패드를 닫으면 원래 켜져 있었을 때만 다시 켜진다.

### 차량번호 규칙

이 차고지 차량은 전부 1000번대(첫 자리가 항상 1)다. 이걸 이용해서:

- 세 자리만 들리면 앞에 1을 붙인다 (`042` → `1042`)
- 첫 자리가 1이 아니게 들리면 1로 고친다 (`7042` → `1042`)
- 이렇게 보정된 칸은 호박색 테두리로 표시되니 나중에 확인하면 된다

## 저장되는 곳

입력한 차량번호는 **폰 안에만** 저장된다(localStorage). 서버로 보내지 않고,
앱을 껐다 켜도 그날 순회 내용은 그대로 남아 있다. 야간 근무를 감안해
오전 9시를 기준으로 날짜를 넘긴다(새벽 3시 입력도 전날 순회로 묶임).

## 개발

정적 파일뿐이라 빌드 과정이 없다. 파이썬만 있으면 된다.

```bash
python -m http.server 5180
```

`http://localhost:5180` 접속. 단, **마이크는 HTTPS 또는 localhost에서만** 동작한다.

### 배치도 데이터 다시 만들기

`src/yard-data.js`는 엑셀에서 자동 생성한 파일이라 직접 고치지 않는다.
배치가 바뀌면 원본 엑셀을 `reference/차고지 프린트.xlsx`에 두고:

```bash
python tools/build_yard.py
```

`신차고지-순서` 시트의 병합 셀을 읽어 15열 × 20행 그리드로 변환한다.
순회 번호가 1~109 연속이 아니면 오류로 멈춘다.

### 테스트

브라우저로 연다 (Node.js 불필요):

- `tools/test.html` — 한글 숫자 파서 (57건, 1000~1999 왕복 검사 포함)
- `tools/voice.test.html` — 음성 엔진의 확정 처리·자동 확정·재시작·되먹임 차단 (28건)

탭 제목에 `PASS n` / `FAIL n`이 뜬다.

### 배포

`src/build.js`(앱에 표시되는 버전)와 `sw.js`의 캐시 이름을 함께 갱신한다.
**배포 전에 반드시 실행해야** 아이폰이 옛 파일을 계속 쓰는 일이 없다.

```bash
python tools/stamp_build.py
```

그 뒤 커밋하고 push 하면 GitHub Pages가 알아서 올린다.

## 구조

```
index.html          화면 뼈대
src/app.js          화면 조립, 입력 처리, 인쇄
src/app.css         야간용 다크 UI + 인쇄 전용 레이아웃
src/plate.js        한글/아라비아 숫자 → 차량번호 (브라우저 API 없음, 순수 로직)
src/voice.js        iOS 사파리 음성 인식 래퍼, 소리·안내음성
src/store.js        localStorage 저장
src/yard-data.js    자동 생성된 배치도 (수정 금지)
src/build.js        자동 생성된 배포 버전 (수정 금지)
version.json        배포 버전 확인용 (수정 금지)
tools/build_yard.py 엑셀 → yard-data.js
tools/stamp_build.py 배포 버전 도장
sw.js               오프라인 캐싱
reference/          원본 엑셀 등 (저장소에 올리지 않음)
```

## 알려진 제약

- **음성 인식은 인터넷이 필요하다.** 애플 서버로 보내서 인식하기 때문에 전파가
  약한 곳에서는 안 된다. 이럴 때 쓰라고 키패드를 넣어뒀다. 앱 자체는 오프라인에서도
  뜨고 입력·저장은 정상 동작한다.
- iOS 사파리는 발화가 끝날 때마다 인식을 끊는다. 앱이 자동으로 다시 켜지만
  아주 짧은 공백이 생긴다. 한 자리씩 또박또박 부르는 게 정확하다.
- 에어팟을 쓸 때 안내 음성이 자기 마이크로 다시 들어가지 않도록, 말하는 동안
  인식을 잠깐 막는다.
- **프린터 와이파이는 앱이 대신 잡아줄 수 없다.** iOS에는 웹앱이 쓸 수 있는
  와이파이 API가 없고, 네이티브 앱이라도 `NEHotspotConfiguration` 권한(유료 개발자
  계정)이 필요하다. 단축어 앱에도 특정 네트워크 접속 동작이 없다. 그래서 인쇄를
  누르면 골라야 할 이름(`DIRECT-s0-EPSON-WF-C579R Series`)을 띄워주는 데까지만 한다.

## 새 버전 받기

앱을 켤 때마다 `version.json` 을 캐시를 건너뛰고 받아와 지금 돌고 있는 것과 비교한다.
다르면 캐시와 서비스 워커를 지우고 알아서 다시 받는다. 사용자가 할 일은 없다.

한 번 받아봤는데도 그대로면 무한 새로고침 대신 화면에 알리기만 한다. 그때는
**진단 → 최신 버전 받기** 를 누른다. 입력해 둔 차량번호는 어느 쪽이든 지워지지 않는다.

그래도 안 되면 설정 → Safari → 고급 → 웹사이트 데이터에서 해당 항목을 지운다.
