# 특이사항 받아쓰기

차량번호마다 서류철이 하나씩 있고, 그것을 한 권씩 꺼내 일지에 특이사항이 있는지
본다. 지금까지는 특이사항이 있는 철을 따로 빼 작은 책상에 쌓아 두었다가 PC 앞에
앉아 다시 타이핑했다. 쌓아 둔 철이 책상에서 떨어지는 일이 한두 번이 아니었다.

이 앱은 **철을 넘기는 그 자리에서 말로 받아 적는다.** 다시 타이핑하지 않는다.

---

## 쓰는 법

1. 아이폰 사파리로 `/daywork/` 를 연다
2. 공유 버튼 → **홈 화면에 추가**
3. 홈화면 아이콘으로 실행 (주소창 없는 전체화면)

**음성 입력 시작**을 누르고 철을 넘기면서 이렇게 부른다.

```
"천백이십"        → 1120 을 받고 내용을 기다린다
"대차"            → 1120 / 대차 로 쌓고 다시 번호를 기다린다

"천백이십 대차"    → 한 호흡에 불러도 된다
```

- 번호는 **"천"을 붙여 끝까지** 부른다 — `"천십이"`(1012) `"천칠백사십구"`(1749).
  자리별로 부르는 `"공이이"`(1022) 도 받는다. 1~2자리로 짧게만 부르지 않으면 된다.
- 특이사항 없는 차는 **"없음"** (패스 / 빈칸 도 같은 뜻) — 적지 않고 넘어간다
- 잘못 들어갔으면 **"정정"** 또는 **"이전"**
- 손이 비면 **어휘 버튼**이 더 빠르고 정확하다. 자주 쓰는 여덟 개가 펴져 있고
  나머지는 [더 보기]. 순서는 PC 프로그램의 버튼 배열과 같다
- 음성이 안 될 땐 **키패드**. 앞자리 1은 고정이라 **세 자리만** 누르면 된다
- 받은 것은 아래 목록에 쌓인다. 눌러서 지울 수 있다

### 조용히 사라지는 기록이 없게

- 내용을 기다리는 중에 **숫자가 들리면** 그건 특이사항이 아니라 다음 차다.
  앞 차는 **'내용 없음'** 카드로 남겨 두고 넘어간다 (버리지 않는다)
- **명부에 없는 번호도 막지 않는다.** 노랗게 '명부에 없음' 으로 표시만 하고 적는다.
  실재하는 차를 못 적는 것이 가장 나쁘다

## 근무일

PC 의 `daywork.py` 와 **같은 규칙**을 쓴다 — **06:30 이전은 전날**로 친다.
자정에 넣든 새벽 1시에 넣든 같은 날 일지로 들어간다.

순회앱 `src/store.js` 에도 `workDate()` 가 있지만 그쪽은 **오전 9시 기준**이라
가져다 쓰면 안 된다. 평소 입력 시각(자정~1시)에는 두 규칙이 같은 답을 내서
한동안 멀쩡해 보이다가, 아침 7시에 몰아 넣는 날 조용히 하루가 밀린다.
`tools/daywork.test.html` 에 못으로 박아 두었다.

## 차량번호 명부

운영자가 불러 준 구간을 `src/roster.js` 에 둔다 (181개).

```
1012~1031, 1113~1170, 1201~1209, 1301~1305,
1333~1355, 1501~1512, 1701~1754
```

실제 보유 대수보다 조금 넓은데 그 방향이 안전하다. 넓으면 "있을 수 없는 번호"
몇 개를 못 걸러낼 뿐이지만, 좁으면 멀쩡한 차가 막힌다.
그동안 일지에 적힌 87종은 하나도 빠짐없이 이 안에 들어간다.

## 어휘

`src/words.js` 는 PC 프로그램의 `words.json` + `word_counts.json` 에서 뽑는다.
PC 에서 단어를 고치거나 순서가 바뀌면 다시 뽑고 배포한다.

```bash
python tools/build_daywork_words.py
```

## 구조

```
index.html          화면 뼈대
manifest.json       홈화면 아이콘 (순회·안내와 따로 잡힌다)
sw.js               오프라인 캐시 — 'daywork-' 이름으로 따로 쓴다
src/app.js          화면 조립, 음성·버튼·키패드 연결
src/app.css         야간용 다크 UI
src/entry.js        말 한 마디 -> 카드 한 장 (순수 로직)
src/roster.js       차량번호 명부 (순수 로직)
src/workdate.js     근무일 계산 (순수 로직)
src/listen.js       iOS 음성 인식 래퍼 — "한 마디 = 글자 한 덩어리"
src/store.js        localStorage ('daywork:' 접두사)
src/words.js        특이사항 어휘 (자동 생성)

../src/plate.js     순회앱과 공용 — 한국식 숫자 -> 차량번호. 고치지 않는다
../src/voice.js     순회앱과 공용 — beep / primeAudio 만 가져다 쓴다
```

`listen.js` 를 `voice.js` 와 따로 둔 이유: 저쪽은 들은 말에서 **번호와 명령만**
토큰으로 골라 넘긴다. 여기는 번호 뒤에 "브레이크 소음" 같은 **자유로운 말**이
따라오므로 글자 그대로가 필요하다. 번호가 없는 말은 `voice.js` 가 아무것도
넘기지 않으므로 그대로는 쓸 수 없고, 고치면 매일 돌고 있는 순회앱이 흔들린다.
그래서 저쪽에서 비싸게 얻은 교훈(onend 재시작, 누적 전사 잘라내기, 한 마디마다
세션 끊기, 되먹임 차단)만 가져와 다시 썼다.

## 테스트

서버가 있어야 모듈을 읽는다.

```bash
python -m http.server 5181
```

| 주소 | 보는 것 |
|---|---|
| `/tools/daywork.test.html` | 번호 파싱·상태기계·명부·근무일 (순수 로직) |
| `/tools/daywork.app.test.html` | 앱을 실제로 띄워 눌러 보는 검사 |

`document.title` 이 `PASS n` / `FAIL n` 이 된다. 공용 파일을 고쳤으면
`/tools/app.test.html`(순회) 과 `/tools/guide.test.html`(안내) 도 함께 돌려
기존 개수가 그대로인지 본다.
