# 특이사항 받아쓰기

차량번호마다 서류철이 하나씩 있고, 그것을 한 권씩 꺼내 일지에 특이사항이 있는지
본다. 지금까지는 특이사항이 있는 철을 따로 빼 작은 책상에 쌓아 두었다가 PC 앞에
앉아 다시 타이핑했다. 쌓아 둔 철이 책상에서 떨어지는 일이 한두 번이 아니었다.

이 앱은 **철을 넘기는 그 자리에서 말로 받아 적는다.** 다시 타이핑하지 않는다.

주소: `/daywork/` · 아이폰 사파리로 열어 **홈 화면에 추가**하면 아이콘이 따로 잡힌다.

---

## 쓰는 법

**음성 입력 시작**을 누르고 철을 넘기면서 부른다.

```
"천백이십"        → 1120 을 받고 내용을 기다린다
"대차"            → 2초쯤 말이 없으면 카드로 쌓고 다시 번호를 기다린다

"천백이십 대차"    → 한 호흡에 불러도 된다
```

- 번호는 **"천"을 붙여 끝까지** 부른다 — `"천십이"`(1012) `"천칠백사십구"`(1749).
  자리별로 부르는 `"공이이"`(1022) 도 받는다. 1~2자리로 짧게만 부르지 않으면 된다
- 특이사항 없는 차는 **"없음"** (패스 / 빈칸 도 같은 뜻) — 적지 않고 넘어간다
- 잘못 들어갔으면 **"정정"** 또는 **"이전"**

버튼은 넷뿐이다. 손이 비었을 때만 쓴다.

| | |
|---|---|
| **◀ 이전** | 방금 것을 되돌린다 |
| **확인** | 다 말했으니 기다리지 말고 지금 넣는다 |
| **없음** | 이 차는 특이사항 없음 |
| **키패드** | 음성이 안 될 때. 앞자리 1은 고정이라 **세 자리만** 누른다 |

### 기다리는 시간

| | |
|---|---|
| 다 부른 번호 (`천삼백오십이`) | **0.15초** — 더 이어질 수 없으므로 바로 |
| 단위로 끝난 번호 (`천백이십`) | **1.5초** — `천백이십사` 가 될 수 있어 기다린다 |
| 내용 | **2초** |

**천천히 끊어 불러도 된다.** `천백… 이십` 처럼 쉬어도 중간 토막을 확정하지 않는다.

여기서 한 번 크게 틀렸다. 처음에는 "`천`, `천백` 처럼 **단위로 끝나는 글자**면 아직
덜 부른 것" 으로 보았는데, **사파리는 "천" 을 글자가 아니라 숫자 `1000` 으로 받아
적는다.** 부르는 동안 전사는 `1000` → `1100` → `1120` 으로 흘러가고, `1000` 도 네
자리라 "다 부른 번호" 로 보여 0.15초 만에 확정돼 버렸다 — 말하자마자 1000 이
들어간 이유다.

그래서 판단 근거를 **명부**로 바꿨다. `1000`·`1100` 은 명부에 없고 `1120` 은 있다.
명부에 없는 번호를 혼자 불렀으면 아직 덜 부른 것일 수 있으므로 더 기다린다.
끝내 그 번호면 그대로 받는다 — 명부에 없다고 막지는 않는다(노랗게 표시만).

영원히 기다리지는 않는다. 두 번까지만 더 기다리고 넘긴다(말이 끊긴 줄도 모르고
멈춰 있지 않게). **기다릴 때는 짧은 길을 쓰지 않는다** — 그러지 않으면 세 번이
0.45초 만에 소진돼 기다린 보람이 없다.

기다리기 싫으면 **[확인]** 을 누른다. 번호 자리에서도 내용 자리에서도 듣는다.

### 조용히 사라지는 기록이 없게

- 내용을 기다릴 때 들린 말은 **그냥 내용이다. 번호가 섞여 있어도 마찬가지다.**
  실제 일지 두 달치 220건 중 98건(45%)이 내용 안에 번호를 담고 있고
  (`1118 대차`, `1138-> 1142 차량 교체`), 55건(25%)은 번호로 시작한다.
  처음에는 "내용 기다리는 중에 숫자가 들리면 다음 차"로 만들었다가
  `1352` 뒤에 `1305호로 대차`를 부르면 통째로 어긋나는 것을 보고 바로잡았다
- **번호만 달랑** 말했을 때에만 다음 차로 넘어간다. 앞 차는 **'내용 없음'** 카드로
  남겨 두고 간다 (버리지 않는다). 내용이 번호 하나뿐인 경우는 그 220건에 없었다
- **명령도 그 말 전체가 명령일 때만** 명령이다. `노선 안내방송 없음`이 건너뛰기로,
  `운행 취소`가 되돌리기로 읽히면 내용이 통째로 사라진다
- 한 호흡에 `천삼백오십이 1305호로 대차`처럼 불러도 **첫 낱말만 번호로** 본다.
  띄어 말하지 않으면 번호와 내용의 숫자가 한 덩어리로 읽혀 엉뚱한 번호가 나온다
- **명부에 없는 번호도 막지 않는다.** 노랗게 '명부에 없음' 으로 표시만 하고 적는다.
  실재하는 차를 못 적는 것이 가장 나쁘다

## PC 로 보내기

**[PC로 보내기]** 를 누르면 그날 받은 것을 GitHub 저장소의 `inbox` 가지에
`daywork-<날짜>.json` 으로 올린다. 사무실 PC 가 그것을 받아 일일일지
프로그램에게 넘기고, 일지 프로그램이 엑셀에 적는다.

```
폰 ──> GitHub inbox ──git──> sctc-copy ──텍스트──> daywork.py ──> 엑셀
                            (이미 5초마다 보는 중)   (ExcelManager 그대로)
```

PC 쪽은 **토큰이 필요 없다** — 이 PC 의 git 이 이미 GitHub 에 로그인돼 있어
`inbox` 가지를 그냥 받아온다. 일지 창이 켜져 있으면 그 창이 30초 안에 집어 적고,
꺼져 있으면 `daywork.py --apply` 가 창 없이 **엑셀을 열고 적고 바로 닫는다**.

- 폰(LTE)과 PC(사내망)는 서로 직접 닿을 수 없어서 둘 다 닿는 GitHub 에 놓고 간다.
  순회앱이 쓰는 길과 같고, 파일 이름만 `daywork-` 로 갈라 둔다
- 토큰은 **[진단] → PC 전송 토큰**에서 한 번만 넣으면 계속 쓴다.
  처음에는 순회앱에 넣어 둔 것을 읽어 쓰면 된다고 보았는데 그렇지 않았다 —
  **iOS 는 홈화면에 추가한 웹앱마다 저장 공간을 따로 준다.** 같은 주소라도 순회앱
  아이콘과 이 앱 아이콘은 서로의 저장소를 보지 못한다. 그래서 이 앱도 자기 것을
  가진다 (`daywork:ghtoken`). 사파리로 열어 순회앱 것이 보이면 그대로 쓴다.
  토큰은 주소만 아는 남이 운행일지에 가짜 기록을 넣지 못하게 막는 역할도 한다
- 같은 날 여러 번 눌러도 된다. 덮어쓰기이고, PC 는 (날짜, 차량번호) 로 적는다
- 내용 없는 카드는 보내지 않는다 (엑셀에 빈 줄이 생기므로)

자정에 한 번, 12시 30분에 또, 새벽 1시에 또 — 또는 한 번에 몰아서. 어느 쪽이든 된다.

## 기록

**[기록]** 에 날짜별로 그날 받은 것과 **변경 기록**이 남는다.

```
01:12  입력  1120  대차
01:14  수정  1120  대차 → 세차      ← 바뀌기 전 값이 남는다
01:20  지움  1121  에어컨 고장
01:31  PC로 보냄  7건
```

카드 목록은 "지금 모습" 만 보여 주므로, 덮어쓰거나 지운 순간 그 전에 무엇이
있었는지 알 길이 없다. 그래서 바뀌기 전 값을 함께 남긴다. 90일이 지난 날은
켤 때 저절로 치운다.

## 근무일

PC 의 `daywork.py` 와 **같은 규칙**을 쓴다 — **06:30 이전은 전날**로 친다.
자정에 넣든 새벽 1시에 넣든 같은 날 일지로 들어간다.

순회앱 `src/store.js` 에도 `workDate()` 가 있지만 그쪽은 **오전 9시 기준**이라
가져다 쓰면 안 된다. 평소 입력 시각(자정~1시)에는 두 규칙이 같은 답을 내서
한동안 멀쩡해 보이다가, 아침 7시에 몰아 넣는 날 조용히 하루가 밀린다.
`tools/daywork.test.html` 에 못으로 박아 두었다.

## 최신 버전 받기

켤 때마다 `version.json` 을 캐시 없이 받아와 지금 돌고 있는 것과 비교한다.
새 것이 올라왔으면 한 번은 알아서 받는다. 그래도 그대로면 **[진단] → 최신 버전 받기**.

순회앱의 같은 기능과 다른 점이 하나 있다 — **자기 것만 지운다.** 순회앱 쪽은
이 도메인의 캐시를 전부 지우고 서비스 워커를 모두 해제하는데, 세 앱이 한 도메인에
올라가 있으므로 그대로 따라 하면 순회앱의 오프라인 캐시와 워커까지 날아간다.
여기서는 `daywork-` 캐시와 scope 가 `/daywork/` 인 워커만 건드린다.

## 구조

```
index.html          화면 뼈대
manifest.json       홈화면 아이콘 (순회·안내와 따로 잡힌다)
sw.js               오프라인 캐시 — 'daywork-' 이름으로 따로 쓴다
version.json        배포 시각 (자동 생성)
src/app.js          화면 조립, 음성·버튼·시트 연결
src/app.css         야간용 다크 UI
src/entry.js        말 한 마디 -> 카드 한 장 (순수 로직)
src/roster.js       차량번호 명부 (순수 로직)
src/workdate.js     근무일 계산 (순수 로직)
src/listen.js       iOS 음성 인식 래퍼 — "한 마디 = 글자 한 덩어리"
src/store.js        localStorage ('daywork:' 접두사)
src/log.js          변경 기록 (바뀌기 전 값까지)
src/sync.js         PC 로 보내기 (GitHub inbox 가지)
src/update.js       최신 버전 받기
src/build.js        배포 시각 (자동 생성)

../src/plate.js     순회앱과 공용 — 한국식 숫자 -> 차량번호. 고치지 않는다
../src/voice.js     순회앱과 공용 — beep / primeAudio 만 가져다 쓴다
```

`listen.js` 를 `voice.js` 와 따로 둔 이유: 저쪽은 들은 말에서 **번호와 명령만**
토큰으로 골라 넘긴다. 여기는 번호 뒤에 "브레이크 소음" 같은 **자유로운 말**이
따라오므로 글자 그대로가 필요하다. 번호가 없는 말은 `voice.js` 가 아무것도
넘기지 않으므로 그대로는 쓸 수 없고, 고치면 매일 돌고 있는 순회앱이 흔들린다.
그래서 저쪽에서 비싸게 얻은 교훈(onend 재시작, 누적 전사 잘라내기, 한 마디마다
세션 끊기, 되먹임 차단)만 가져와 다시 썼다.

## 테스트

서버가 있어야 모듈을 읽는다.

```bash
python -m http.server 5181
```

| 주소 | 보는 것 |
|---|---|
| `/tools/daywork.test.html` | 번호 파싱·상태기계·명부·근무일 (순수 로직) |
| `/tools/daywork.app.test.html` | 앱을 띄워 눌러 보는 검사. **가짜 음성 엔진**을 끼워 실제 흐름 그대로 돌린다 |

`document.title` 이 `PASS n` / `FAIL n` 이 된다. 공용 파일을 고쳤으면
`/tools/app.test.html`(순회) 과 `/tools/guide.test.html`(안내) 도 함께 돌려
기존 개수가 그대로인지 본다.

검사에서 **`hidden` 속성만 보지 말 것.** `.sheet-bg` 처럼 `display` 를 준 요소는
`hidden` 이 먹지 않아, 속성은 true 인데 화면은 덮여 있는 일이 실제로 있었다.
`getComputedStyle(...).display` 까지 본다.
